# Ryan — Personal Website

A responsive, static portfolio built with HTML, CSS and JavaScript.

Live site: https://ryanuwu1020.github.io/site/

## Preview locally

Run `python -m http.server 8080` in this folder, then visit http://localhost:8080.

## Deployment

In GitHub, open **Settings → Pages**. Select **Deploy from a branch**, choose **main** and **/ (root)**, then Save. GitHub Pages publishes the site automatically after changes to main.

## Editing

- `index.html`: text, sections and links
- `style.css`: colors, layout and responsive styles
- `script.js`: terminal interaction and current year
- `favicon.svg`: browser icon

Google Fonts is optional; system fonts are used if unavailable. No build step, tracking or third-party JavaScript is required.
